# Coffee POS

A complete Coffee Shop Management System built with PHP, MySQL, and Bootstrap 5.

## Features
- Admin, Staff, Customer roles
- Product & Category management
- Shopping Cart & Checkout
- POS System
- Order Management
- Inventory Tracking
- Sales Reports
- Authentication & CSRF Protection

## Setup
1. Import `database/coffee_system.sql`
2. Configure `config/database.php`
3. Access at http://localhost/Coffee POS

## Default Accounts
- Admin: admin@coffee.com / Admin@123
- Staff: staff@coffee.com / Staff@123
- Customer: customer@coffee.com / Customer@123
